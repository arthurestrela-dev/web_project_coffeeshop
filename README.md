# Triple Espresso

Café Triple Peaks

Descrição

O Café Triple Peaks é uma landing page desenvolvida como parte do quarto projeto da TripleTen, com foco em HTML e CSS avançado. O site apresenta uma cafeteria fictícia localizada na biblioteca Triple Peaks, com seções de apresentação, receitas, reserva de mesa e informações de contato.

As funcionalidades são: Navegação por âncoras entre as seções da página, layout responsivo baseado em Flexbox, seção de receitas com vídeos incorporados do YouTube, formulário de reserva, estados de hover para links e botões, e estrutura organizada seguindo a metodologia BEM.

Tecnologias utilizadas: HTML5, CSS3, Flexbox, Metodologia BEM e Google Fonts.

Estrutura do projeto:
Header: apresentação da cafeteria.
Receitas: vídeos com receitas de café.
Reserva: formulário para reserva de mesa.
Footer: redes sociais e informações de copyright.

Melhorias futuras:
Tornar a landing page totalmente responsiva para dispositivos móveis e tablets, adaptando a navegação, as seções e o formulário para diferentes tamanhos de tela.
